## Transition matrix specified

| Initial evidence                                 | Independent replay                                      | Required result                                                      |
| ------------------------------------------------ | ------------------------------------------------------- | -------------------------------------------------------------------- |
| Eligible VIOLATED                                | Eligible VIOLATED                                       | CONFIRMED                                                            |
| Eligible VIOLATED                                | Applicable SATISFIED                                    | NON-REPRODUCED                                                       |
| Eligible VIOLATED                                | NOT APPLICABLE                                          | INCONCLUSIVE                                                         |
| Eligible VIOLATED                                | UNEVALUABLE or missing verdict                          | INCONCLUSIVE                                                         |
| Ineligible initial/replay provenance or approval | Two violations                                          | INCONCLUSIVE                                                         |
| Missing/invalid identity or freshness            | Invalid verification                                    | Rejection or INCONCLUSIVE; never confirmation/non-reproduction       |
| Pending verification                             | Admission/reset/baseline/cancellation/execution failure | INCONCLUSIVE with the separate honest run/trial stop reason          |
| Existing confirmation                            | Unrelated later execution failure                       | Preserve evidenced confirmation; record execution failure separately |

Execution errors are never a predicate verdict or fifth finding classification. Model prose and forged model classification cannot grant authority. Malformed identity/reference input may be rejected; missing replay verdict specifically requires INCONCLUSIVE. Exact references and prior transitions are retained.

## Identity, freshness and lifecycle cases

Tests specify exact predicate ID/version/canonical hash; wrong IDs, versions and hashes; changed definitions requiring new versions, initial evidence and candidates; missing/late/withdrawn approvals; ungrounded specification assertions and unapproved hypotheses. Late approval cannot validate old ineligible evidence: a newly bounded run with newly observed initial evidence and independent replay is required. The original candidate remains immutable. Trusted approval collections and specification grounding are deterministic inputs, not model claims.

Freshness cases include a new verified replay baseline, stale or reused baseline, missing baseline, violated/unevaluable baseline, empty or unrelated assertion references, wrong run/trial references, discovery evidence masquerading as replay, reused original trial, missing/duplicate/foreign observations, incomplete/error/interrupted/truncated observations, and non-violating initial verdicts.

The integration contract admits the complete five-request replay before reset. A nine-request run has enough for five discovery requests but insufficient remaining capacity for replay, so no replay reset is dispatched. Reset/baseline/cancellation/execution failures preserve the original evidence and create no fabricated replay predicate outcome. All successful replay requests use the existing supervisor and shared phase counters; no Gemini calls are needed for deterministic verification.

Later agreeing evaluations append history while retaining consistency. Later contradictory fresh evaluations append both evidence references and mark `consistent: false` after either confirmation or non-reproduction. Old transitions/evidence survive. Another isolated violating replay cannot erase the contradiction; a new initial-plus-replay confirmation attempt is required. Repository tests specify durable reference checks, transactional rejection of forged references, immutable evidence/transitions, and persisted inconsistency.
