## T039 consumer contract specified

The missing `src/engine/minimization/greedy.ts` boundary is consumed via:

- `planDeletion(journey, predicate, index)`: pure single-step deletion planning;
  return a candidate or local rejection with a nonempty reason. Protect producer,
  prerequisite and predicate operands, including JSON/header/status/step-index
  references and extracted variables. Reject invalid indexes. Preserve retained
  definitions, step IDs, predicate identity and input immutability.
- `preservesReduction(input)`: accept only an eligible exact-predicate VIOLATED
  determination on independent valid fresh MINIMIZATION evidence. Reject or
  return false for malformed/ineligible evidence. Deterministic observations must
  support the verdict; an invented VIOLATED label or model prose cannot override
  SATISFIED observations.
- `minimizeFinding(supervisor, run, journey, confirmedFinding)`: orchestrate bounded
  ordered deletion through existing supervised trial infrastructure. Return the
  best verified journey, original/best lengths, finding, append-only attempts,
  stop reason and whether the single-step local criterion was reached.

These are test consumer ports, not production implementation or a second runner.
The helper constructs explicitly requested fixture candidates; it neither selects
removals nor accepts reductions. Existing deterministic predicate evaluation and
T037 confirmation provide controls. Dynamic import is deliberate so typecheck
stays healthy while T039 is absent. Every behavior test loads the boundary before
rejection assertions, so its absence cannot accidentally satisfy a negative test.
