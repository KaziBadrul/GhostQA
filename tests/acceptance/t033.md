## Behavior

One proposal call carries journey rationale, inferred/hypothesized mappings and
unapproved predicate hypotheses. The existing bare-Journey boundary remains
compatible. Strict deterministic validation rejects unknown fields, forged phase,
control/excluded/unknown operations, invalid bindings and mismatched approved
predicate ID/version/hash. Proposed mappings cannot claim declared or observed
provenance; hypotheses cannot grant themselves approval.

The loop uses the existing T032 context builder and provider. Feedback contains
at most ten sanitized observations; responses exceeding 16 KiB are withheld from
feedback, and the existing total context/output limits remain enforced. Configured
credentials, issued tokens and sensitive response fields are symbolic/redacted.
Planning intent/result context, rationale and usage are persisted only after
sanitization. Redaction that changes executable journey semantics or invalidates
a hypothesis hash fails MODEL PLAN ERROR; the unsafe proposal is not persisted.

DECLARED mappings derive from the imported API; INFERRED_DEPENDENCY mappings
retain binding provenance; HYPOTHESIZED_STATE mappings remain proposals;
OBSERVED_TRANSITION mappings cite actual observations without claiming an
unobserved business-state guarantee. Novelty normalizes cosmetic IDs, rationale,
variable names and fresh literal contents while retaining ordered operations,
parameter names, binding/extraction structure, value-source provenance and
predicate identity.

Only RunSupervisor owns planning admission/counters and dispatch authorization.
BudgetManager preflights minimum setup before planning and admits the complete
validated trial before reset. Every useful journey uses a newly verified baseline,
the existing supervised executor and deterministic evaluation of the exact frozen
predicate. The loop records evidence, not finding classifications. No T034 candidate
detection, CLI entrypoint, live discovery, confirmation or later work was added.

Three consecutive valid non-useful proposals stop STAGNATION. Invalid plans,
provider timeout/outage, request/time/journey limits, cancellation and setup failures
stop deterministically without hidden retries. Durable planning intents are
conservative records when cancellation/storage failure leaves a call outcome
unknown. Provider usage is retained as supplied; absent counts are not invented.
