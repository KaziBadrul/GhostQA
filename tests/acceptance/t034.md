## Local acceptance

Initial eligible VIOLATED evidence from verified baseline and completed observed
journey produces SUSPICIOUS. SATISFIED/NOT APPLICABLE initial evaluations produce
no candidate. UNEVALUABLE or ineligible evidence produces INCONCLUSIVE; execution
errors remain execution outcomes and never confer confirmation. No replay,
CONFIRMED/NON-REPRODUCED transition or model classification is implemented.

Exact predicate ID/version/hash, original journey and observation/baseline/trial
references are checked. Duplicate or mismatched observations fail closed.
Developer-approved agent eligibility is checked against stored approval records;
model-authored approval claims cannot confer authority. Ungrounded specification
assertions fail closed. The repository guards exact frozen predicates/scope,
immutable journey, predicate/baseline evaluation and stored sanitized observations
before inserting finding/transition atomically. Known secrets are sanitized using
the active trial vault. Initial reasons contain only deterministic constant text.

The CLI takes strict `{run, inputs}` configuration, previews the frozen scope and
phase policy, and requires explicit `--approve-scope` and an existing project.
Execution requires an exact stored scope approval. It uses the existing configured
Gemini adapter and RunSupervisor; cancellation signals close that supervisor's
gate. No alternate target dispatch, budget manager or provider path was added.
